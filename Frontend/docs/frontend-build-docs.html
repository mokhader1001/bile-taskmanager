Setup

Project Setup

Before any component code is written, scaffold the project and install its dependencies.

Step 1 — Create the project folder with Vite

Vite's React template gives us a working React app in seconds — dev server, JSX support, and a build pipeline, with no manual Webpack/Babel config.

terminal 
npm create vite@latest frontend -- --template react
cd frontend
npm install
Step 2 — Install the extra libraries this app uses

axios for HTTP calls to the backend API, and react-router-dom for client-side page routing (login/signup/tasks without full page reloads).

terminal 
npm install axios react-router-dom
Step 3 — Add Bootstrap (styling)

No component library is used — just Bootstrap 5 loaded from a CDN link, added to the <head> of index.html. This keeps the setup simple: no extra npm package, no build step for CSS.

index.html 
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
/>
Step 4 — Point the frontend at the backend API

Create a .env file in the project root. Vite exposes any variable prefixed with VITE_ to the client code via import.meta.env.

.env 
VITE_API_URL=http://localhost:5000/api
Step 5 — Run it
terminal 
npm run dev

Step 03 of 9

src/AuthContext.jsx

Global authentication state (React Context)

Instead of passing the logged-in user down through props, we use React's Context API so any component can call useAuth() and get the user, plus login()/logout() functions.

Part 1 — Imports + create the context

createContext(null) creates a context object. null is the default value used only if a component tries to read it outside of a provider.

js 
import { createContext, useContext, useState } from "react";

const AuthContext = createContext(null);
Part 2 — Provider + initial state

The initializer function passed to useState only runs once, on first render. It checks localStorage for a previously saved user so that refreshing the page doesn't log you out.

jsx 
export function AuthProvider({ children }) {
  const [user, setUser] = useState(() => {
    const saved = localStorage.getItem("user");
    return saved ? JSON.parse(saved) : null;
  });
Part 3 — login()

Called after a successful API login. Persists both the user object and the JWT token to localStorage, then updates state so the whole app re-renders as "logged in".

js 
  const login = (userData, token) => {
    localStorage.setItem("user", JSON.stringify(userData));
    localStorage.setItem("token", token);
    setUser(userData);
  };
Part 4 — logout()

Clears everything from storage and resets state, which sends the user back to the login screen via ProtectedRoute.

js 
  const logout = () => {
    localStorage.removeItem("user");
    localStorage.removeItem("token");
    setUser(null);
  };
Part 5 — Provider return + the useAuth hook

We expose { user, login, logout } to every child. useAuth() is just a shortcut so components don't need to import useContext and AuthContext everywhere.

jsx 
  return (
    <AuthContext.Provider value={{ user, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export const useAuth = () => useContext(AuthContext);

src/AuthContext.jsx 
import { createContext, useContext, useState } from "react";

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(() => {
    const saved = localStorage.getItem("user");
    return saved ? JSON.parse(saved) : null;
  });

  const login = (userData, token) => {
    localStorage.setItem("user", JSON.stringify(userData));
    localStorage.setItem("token", token);
    setUser(userData);
  };

  const logout = () => {
    localStorage.removeItem("user");
    localStorage.removeItem("token");
    setUser(null);
  };

  return (
    <AuthContext.Provider value={{ user, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export const useAuth = () => useContext(AuthContext);
Step 04 of 9

src/api.js

Shared Axios instance — every network call goes through this

Rather than importing axios directly in every page and repeating the base URL and auth header, we configure it once here.

Part 1 — Create the instance

axios.create() makes a pre-configured axios instance. The base URL comes from the VITE_API_URL environment variable (set in .env), falling back to localhost for local dev.

js 
import axios from "axios";

const API = axios.create({
  baseURL: import.meta.env.VITE_API_URL || "http://localhost:5000/api",
});
Part 2 — Request interceptor

This function runs before every outgoing request. It reads the JWT saved at login time and attaches it as a Bearer token, so we never have to manually set auth headers on individual API calls.

js 
API.interceptors.request.use((config) => {
  const token = localStorage.getItem("token");
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

export default API;

src/api.js 
import axios from "axios";

// One shared axios instance for the whole app.
const API = axios.create({
  baseURL: import.meta.env.VITE_API_URL || "http://localhost:5000/api",
});

// Attach the saved token to every request automatically.
API.interceptors.request.use((config) => {
  const token = localStorage.getItem("token");
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

export default API;

Route guard — blocks pages from unauthenticated users

A tiny wrapper component. Anything passed in as children only renders if a user is logged in; otherwise it redirects to /login.

Part 2 — The guard logic

One line: if user exists, render whatever was wrapped (children); otherwise render a redirect to /login.

  const { user } = useAuth();
  return user ? children : <Navigate to="/login" />;

import { useState } from "react";
import { Link, useNavigate } from "react-router-dom";
import API from "../api";
import { useAuth } from "../AuthContext";

export default function Login() {
    const [form, setForm] = useState({ email: "", password: "" });
    const [error, setError] = useState("");
    const { login } = useAuth();
    const navigate = useNavigate();

    const change = e => setForm({ ...form, [e.target.name]: e.target.value });

    const submit = async e => {
        e.preventDefault();
        setError("");
        try {
            const { data } = await API.post("/auth/login", form);
            login(data.user, data.token);
            navigate("/");
        } catch (e) {
            setError(e.response?.data?.message || "Login failed");
        }
    };

    return (
        <div className="min-vh-100 d-flex">
            <div className="w-50 d-none d-md-flex flex-column justify-content-center p-5 text-white"
                style={{ background: "linear-gradient(135deg,#071d52,#0866e9)" }}>
                <h2 className="fw-bold mb-5">✓ Task Manager</h2>
                <h1 className="fw-bold display-5">
                    Organize tasks.<br />Boost productivity.<br />Achieve more.
                </h1>
                <p className="fs-5 mt-3 opacity-75">
                    Manage your tasks, deadlines and projects all in one place.
                </p>
            </div>

            <div className="flex-grow-1 d-flex align-items-center justify-content-center bg-light p-4">
                <div className="bg-white p-5 rounded-4 shadow" style={{ width: "100%", maxWidth: 480 }}>
                    <div className="text-center mb-4">
                        <h2 className="fw-bold mt-2">Welcome Back</h2>

                        <input className="form-control form-control-lg mb-3" type="email"

                            value={form.email} onChange={change} required />

                        <label className="form-label">Password</label>
                        <input className="form-control form-control-lg mb-4" type="password"
